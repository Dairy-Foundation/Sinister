Sinister is an api stub and utilities library for classpath scanning and hot
reloading, you may want to use it if you need to write a non-android ftc library
that needs to interact with sloth, or a jvm equivalent that doesn't yet exist.

Check out [Sloth](https://github.com/Dairy-Foundation/Sloth) for more
information.
